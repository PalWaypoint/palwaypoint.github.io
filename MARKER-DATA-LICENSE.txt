PalWaypoint map data and artwork — independent sources
Retrieved September 30, 2026.

Location positions, English names and encounter metadata:
Arkive game-data extraction, copyright Yihao Liu (tc-imba), CC BY-NC 4.0.
https://github.com/arkive-games/arkive/tree/master/tools/apps/palworld/maps
https://data-palworld.tc-imba.com/markers/MainWorld.json
https://data-palworld.tc-imba.com/markers/WorldTree.json
English names: locales/en-US/markers/<map>.json at the same endpoint.
Modified: mapped game types to PalWaypoint categories, converted records to
compact arrays, excluded habitat sample points, and joined English names.

All 407 effigies: PalDex's direct game-asset extraction.
https://github.com/catrenelle/PalDex/tree/master/data
Source actor identifiers are retained. Its code license does not transfer
ownership of the underlying game data or artwork.

All 1,816 egg spawners, 59 camps and 22 Kinship Peaches:
https://github.com/oMaN-Rod/palworld-save-pal/tree/main/data/json
Files eggs_spawners.json, camps.json and kinship_peach.json.
Game-extracted instance identifiers are retained; eggs are grouped by region.

Chest previews: independently extracted Arkive item acquisition tables.
https://data-palworld.tc-imba.com/items.json
Probabilities are kept separately by loot area and chest grade. The source
does not fix each location's grade, appearance odds or respawn time.

Additional resource nodes, fishing salvage locations, and dungeon entrances:
PalDB's public game map data, https://paldb.cc/en/Palpagos_Islands and
https://paldb.cc/en/The_World_Tree . Source data literals:
https://paldb.cc/js/map_data_en.js and https://paldb.cc/js/treemap_data_en.js
Parsed only JSON data literals; no site application code was copied or run.
Duplicate locations within the same type are omitted. Source indices and
input hashes are retained for reproducibility. Game artwork is Pocketpair's.

Map textures and calibration: PalDex game-extracted map.webp and tree.webp.
https://github.com/catrenelle/PalDex/tree/master/frontend/assets
Textures uniformly reduced from 8192 to 4096 pixels, without cropping.
Coordinate conversion: https://github.com/palworldlol/palworld-coord
Terrain elevation: Palworld Save Pal's game-extracted DEM tiles, with its
GPL-3.0 license notices bundled in terrain/LICENSE.txt and terrain-tree/LICENSE.txt.
https://github.com/oMaN-Rod/palworld-save-pal
Surface region geometry: independently extracted Arkive game data,
CC BY-NC 4.0. Source geometry belongs to Pocketpair.
https://github.com/arkive-games/arkive

Category badges: original PalWaypoint compositions using Lucide Static 1.48.0
pictograms, ISC license in icons/palwaypoint/LICENSE-lucide.txt.
Pal portraits and numbered roster: https://paldb.cc/en/Pals
Item portraits: https://resource-palworld.tc-imba.com/icons/
Per-item source URLs are listed in icons/item-art/sources.json.
Capture sphere controls are original CSS artwork.

Every active map record contains an independent source identifier. Previous
IDs are retained solely for matching existing browser progress; no previous
location labels, loot previews or imported icon files are retained.
Coverage reflects these sources, not every location in the game.

Palworld names, game data and underlying artwork belong to Pocketpair, Inc.
This is an unofficial fan project. Source code licenses do not transfer
ownership of game artwork. No third-party application code was copied.
